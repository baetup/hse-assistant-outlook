# HSE Assistant · Outlook add-in

Outlook add-in ("Order check") for HSE Assistant. It reads the open email, or the emails you select in new Outlook, and hands their subject, recipients and date to HSE Assistant, which reports which order emails are tracked and pre-fills untracked ones.

- `manifest.xml` – add-in manifest (install from URL: `https://baetup.github.io/hse-assistant-outlook/manifest.xml`)
- `taskpane.html` – the task pane
- `assets/` – icons

Served with GitHub Pages from the `main` branch root. The add-in stores no data.
