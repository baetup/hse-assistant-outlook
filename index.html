HSE Assistant · Order check

Outlook add-in that checks whether supplier order emails are tracked in HSE Assistant.

Install

  1. Open aka.ms/olksideload and sign in with your work account.
  2. My add-ins → Custom Addins → Add a custom add-in → Add from File.
  3. Choose manifest.xml (download it from this repository, or use the copy in your Documents\HSE Assistant\Outlook add-in folder).

The add-in reads the email you open or select, and can set Outlook categories (e.g. "Order Incomplete") from the statuses you copy from HSE Assistant. Nothing is stored on this site.
